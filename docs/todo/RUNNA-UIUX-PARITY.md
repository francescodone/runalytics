# Retired UI Parity Backlog

Runna visual parity is no longer the design target. The former U-numbered
layout, navigation and styling requirements are retired; references to them in
historical feature notes are provenance, not open implementation instructions.

Use the [Runalytics Glass Design System](../../plan/ui-system-unification.md)
for current UI requirements and verification. The
[feature backlog](RUNNA-FEATURE-PARITY.md) and external research remain available
for training behavior; they do not override the design system.
